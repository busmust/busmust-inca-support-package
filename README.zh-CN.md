# BUSMUST INCA J2534 支持包

[English](README.md)

中文图文步骤见[先看这里：BUSMUST 设备接入 INCA 指南](先看这里_BUSMUST设备接入INCA指南.pdf)。

本包将本地 BUSMUST CAN / CAN FD 通道提供给 Windows J2534 客户端，包含
J2534 04.04 接口、设备配置程序和匹配的 BMAPI。请另外安装正常的 BUSMUST USB
驱动。INCA 软件及其各项功能的许可证由客户正常取得，本包不提供 ETAS 授权。

## 下载

请打开 [GitHub Releases](https://github.com/busmust/busmust-inca-support-package/releases)，
下载最新发布版本中的 Windows 安装包（ZIP），解压后即可安装，包含 Windows
x86/x64 运行组件、中英文说明和中文图文指南。页面自动生成的 **Source code** 压缩包用于
源码开发，不含可直接安装的运行组件。源码也可从 [Gitee 镜像](https://gitee.com/busmust/busmust-inca-support-package) 获取。

## 安装一次

1. 解压完整客户 ZIP，退出 INCA 及其硬件服务，双击 `Install.cmd`，接受 Windows 管理员提示。
   安装时不要求插设备。
2. 使用 INCA 原有快捷方式启动。在硬件配置中添加 J2534 系统，选择
   **BUSMUST - BMJ2534**，API 版本保持 **04.04**。
3. 点击 INCA 的外部设备配置按钮，打开 **BUSMUST J2534 设备配置**。
4. 恰好一个可用物理 CAN/CAN FD 通道时可使用“自动”；需要指定设备/口时先切换
   “手动”，在“通道”列表直接选择完整名称，例如 `BM-USB-XL4(10356) CH2`。
5. 按实际总线接线选择“关闭”或“120 Ω”终端电阻，点击“保存”即关闭配置窗口；在下一次打开硬件时生效。

也可在开始菜单 **BUSMUST** 中打开设备配置。总线已经正确终端匹配时，不要再随意
增加电阻。模式和电阻按当前 Windows 用户保存；手动模式同时保存准确 UID/物理端口。

默认安装目录为 `%ProgramW6432%\BUSMUST\INCA-J2534`。安装成功后可删除下载 ZIP
和解压目录。安装器不修改 INCA 程序、ETAS DLL、ETAS 全局设置或系统 PATH。

## 插新设备、多设备及切换通道

以后插入新设备，打开配置程序 → 选择设备/通道 → 保存 → INCA 重新初始化，
无需重装。覆盖范围取决于已安装 BMAPI 和 USB 驱动支持的型号；未来的新硬件型号
可能需要升级驱动/BMAPI。配置窗口响应 Windows 设备通知自动刷新，必要时可点“刷新”。
在“通道”列表中按完整的设备型号、序列号和物理口选择通道，刷新时保留同一通道。
原通道消失时显示“已选通道不可用”，禁止保存，不自动换到另一台设备；重新选择有效
通道后恢复。
LIN、远程和虚拟通道不出现在本包列表中。界面跟随 INCA 已保存的中文/英文语言偏好，
其他语言回退到英文。

无配置默认为“自动 + 终端关闭”。每次 Open 只解析一次：恰好一个可用本地物理
CAN/CAN FD 通道时使用，零个报未连接，多个需改用“手动”。四口设备计四个候选，
两台单口计两个，LIN/虚拟/远程不计入。自动不固化 UID；关闭 A 后只接单口 B，
无需重新配置即可打开。自动也可保存自己的关闭/120 Ω。活动连接不会热切到替代设备。

“手动”保存准确 UID/口，缺失就报错，即使只接另一台唯一设备也不替代。只有明确保存
另一手动选择或切回自动才更改绑定。配置损坏或无法读取时会报错。
配置影响下一次连接；更改前按下方步骤释放硬件，更改后重新初始化。
不同 Windows 用户分别保存各自选择。

请在初始化硬件之前选择通道。已经连接时，先释放 INCA 的硬件连接，再打开 Config，
否则被占用的通道可能不在列表中。INCA 7.4.3 已验证可不退出程序，按以下步骤操作：

1. 停止测量、保存实验，返回数据库主窗口（硬件配置窗口中可按 `Ctrl+F7`）。
2. 首次使用时通过 `Edit → Add → Workspace` 新建不含硬件的空白工作区，以后复用。
3. 选中空白工作区，`Ctrl+K` 激活，确认关闭原编辑器，再用 `Ctrl+F3` **打开空白工作区的硬件配置**。
4. 从开始菜单 BUSMUST 打开配置工具，选择通道、修改并保存。
5. 返回原工作区，`Ctrl+K` 激活、`Ctrl+F3` 打开硬件配置，`F3` 初始化并运行原实验。

仅停止测量或仅激活空白工作区不等于释放硬件；完整图示见随包 PDF 第 4 页。
安装、更新、卸载时仍需正常退出 INCA 和使用本包的客户端。

该选择是当前用户后续连接的默认项，并不是分别存入每个 INCA 工作区的独立绑定。
仲裁/数据波特率及其他通信参数仍在 INCA 硬件配置中设置；本配置窗口不回写这些工作区参数。

支持范围为 **INCA 7.X.X**。已验证的环境记录如下；支持范围与已验证记录分开列示，未列出的组合不代表已实测。

| INCA 版本 | 已验证操作系统 |
|---|---|
| 7.3.7 | Windows 10 |
| 7.4.3 | Windows 10 |
| 7.4.3 | Windows 11 |

本包通过 J2534 接入 INCA，不提供原生 ES582 接口。同一 INCA 实验使用一个物理通道。
标准 J2534 客户端可以显式指定 UID/端口，其并发能力取决于客户端。

## 功能及限制

- Classic CAN / CAN FD 监测，以及两种总线上的 ISO-TP 分段收发。
- INCA 中的 XCP、UDS 仍需相应软件功能和许可证；ODX-LINK 诊断需要 ETAS 的
  对应授权和一致的项目，安装本包不会绕过授权。
- FD 扩展包含 SAE `FD_CAN_PS` / `FD_ISO15765_PS` 与 GM `CAN_FD_PS` /
  `ISO15765_FD_PS`；GM 指 General Motors（通用汽车）的扩展命名空间。
  本包不附带 SAE/GM 标准文本，不宣称规范认证。
- Raw FD 使用合法 DLC 长度，最大 64 字节；ISO-TP 长报文受已声明的 J2534
  消息缓冲区容量限制。仅支持 Classic 的物理口会拒绝 FD 协议。
- 不支持的协议、电压或可选服务会返回错误。
- 默认 CAN / 仲裁段采样点为 **75%**，CAN FD 数据段为 **80%**。在“采样点”中
  选择“自定义（仅所选通道）”，可填写整数百分比（1..100）；选“默认”时输入框禁用。
  Classic CAN 只使用 CAN / 仲裁段；数据段只用于 CAN FD，纯 CAN 设备的数据输入禁用。
- 保存的自定义值仅绑定所选手动通道，在下一次打开硬件时读取，不影响当前连接。
  CAN 用该值初始化，之后仍可通过 INCA 的 CAN 参数或标准 `BIT_SAMPLE_POINT` 修改；
  CAN FD 两段值由 Config 提供。
- 硬件拒绝设置或读回超出容差时会返回错误并恢复原配置；恢复失败需关闭并重新打开通道。
  INCA 7.4.3 的原 FD 采样点栏不与 Config 同步，不用于确认硬件实际值。排查时可在
  `CONFIG_APPLIED` 查看请求与读回，在 `CONFIG_REJECTED` 查看失败请求；日志用于诊断，
  无需在每次正常配置时查看。CAN FD 采样点通过 Config 设置，不支持标准 `BIT_SAMPLE_POINT` 参数。
- Raw CAN/CAN FD 周期报文与普通发送按入队顺序共享发送机会。每个周期最多保留一个待处理作业；
  过载时跳过错过的周期，不无限积压或追赶补发，实际周期可能变长。
- Bus-Off 只对本端口做有界恢复；持续故障需要重新连接，不会无限重发或关闭其他口。
- 旧固件拒绝单侧 TX 清除时，本包取消本地软件队列；已经下发到旧硬件的一帧可能
  仍会发送。“软件队列清除成功”不代表该帧已从硬件物理撤销。

## 卸载、更新和排错

关闭 INCA 及其他 J2534 客户端，使用开始菜单“卸载 BUSMUST J2534”或已安装目录
的 `Uninstall.cmd`。只删除本实例登记的 Provider、已知快捷方式和未修改的自有
文件；修改过或额外加入的文件保留并报告。请保存未完全移除的报告。更新遇到修改
过或非本包所有的文件会拒绝覆盖；处理中断后可用同一包重试。
卸载批处理用于双击打开的独立控制台，确认报告后会结束该命令进程。自动化或已有
命令行会话请使用下方 PowerShell 管理命令，不要用 `call` 调用卸载批处理。

无法连接时先关闭占用目标口的其他软件，插入正确设备、刷新，核对型号/SN、通道、
速率和接线。配置保存不会替换 INCA 已经打开的连接。出现警告或错误时，保留 INCA
监控日志以便排查。许可证警告需检查 INCA 对应功能的授权。

高级安装可在 Windows PowerShell 5.1 或 PowerShell 7 中指定专用目录：

```powershell
.\Manage-SupportPackage.ps1 -Action Plan -InstallRoot 'D:\Tools\BUSMUST-J2534'
.\Manage-SupportPackage.ps1 -Action Install -InstallRoot 'D:\Tools\BUSMUST-J2534'
.\Manage-SupportPackage.ps1 -Action Uninstall -InstallRoot 'D:\Tools\BUSMUST-J2534'
```

更新时使用相同安装目录。重解析路径、父级穿越和其他安装实例的所有权会被拒绝。
换一个目录不会自动接管原目录拥有的 Provider。

## 现场诊断日志

默认记录在当前用户 `%LOCALAPPDATA%\BUSMUST\J2534\Logs`。排错时保留对应的
`BMJ2534-*.jsonl` 及其 `.1`、`.2`，同时提供 INCA 版本、监控日志和复现步骤。
日志含运行模块及 BMAPI 哈希、所选 UID/端口、型号/SN/固件、实际配置、连接关闭、
原始错误及低频计数摘要；默认不转储报文负载，可能包含用户名路径和设备标识。

每个日志文件最多4MiB并保留两份轮转，正常保留最近8个会话。日志记录有容量和速率限制，
不等同于完整报文抓取；进程异常、写入失败或限流可能导致记录缺失。
日志目录不可写时不影响通信结果。

支持人员可将64位注册表视图的当前用户 `Software\BUSMUST\J2534` 中 DWORD
`FileLogEnabled` 设置为0以关闭日志；删除该值或设为1恢复默认，下一次打开设备生效。
停止测量或关闭配置窗口不会释放正在使用的通道；重新配置时按前文步骤释放硬件。
